# Design Context

Source: the creator's application plan and subsequent requests in this chat.

- Audience: Windows users who want a local Pomodoro timer, tasks, reports, and desktop widgets for focused work.
- Use cases: start/pause a focus session, plan task estimates, review focus time, and glance at shared timer/task widgets.
- Brand: Orbit. Calm, rounded, polished, quiet, and restrained; coral for focus, teal for short breaks, indigo for long breaks.
- Quality bar: a polished complete desktop application, with consistent icons and careful layout at readable Windows scaling.
- Constraints: Slint software rendering; one process; event-driven updates; installed Segoe UI and tabular timer digits; small vectors rather than icon fonts or bitmap packs. Preserve keyboard accessibility, high contrast, and reduced motion.
- Scope of this pass: polish the existing interface and icons; preserve timer/storage behavior and the requested removal of the large Slint panel. Distribution attribution remains a separate unresolved question.
